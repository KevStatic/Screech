# Screech

Screech is a project by ItzKev (MIT licensed).

Screech revives the dial-up modem: it sends small data (Wi-Fi credentials, links,
contact cards, check-in codes) to every device in earshot with one sound, using
ggwave (FSK, 8–16 bytes/sec). Browser-only, cross-platform, no pairing.
Entered in Kiroween 2026, Resurrection category. Payloads must stay under ~100 bytes.
The UI is a haunted 1980s CRT radio, and every spooky effect must do a real job.

Users: event hosts, teachers, meetup organisers and their attendees.
Core features: send/receive (text, link, Wi-Fi, contact), broadcast room,
presence check-in, sealed (encrypted) mode.
Out of scope: files or images, native mobile apps, a custom modem.
