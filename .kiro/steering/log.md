# Update Kiro log

When invoked:
1. Check what changed with `git status` and `git diff --stat` (staged and unstaged),
   and consider the work done in this session.
2. Open KIRO_LOG.md. Under a heading for today's date (format: "## November 14, 2026"),
   creating it at the end of the file if it doesn't exist, append 1–4 bullet points:
   - what changed, in plain words
   - which Kiro features were used (spec, chat, hook, steering, MCP, property tests, Crew)
   - anything notable: bugs caught, surprises, things that didn't work
3. Never edit or reorder existing entries, and don't modify any other file.
